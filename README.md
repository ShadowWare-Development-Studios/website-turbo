## Project Structure
- `index.html` contains the page content.
- `styles.css` contains the layout, responsive design, and animations.
- `script.js` contains the small interactive mystery button.

This is a static GitHub Pages website, so it does not need a backend server. Keeping the project static makes it easier to deploy and maintain.
